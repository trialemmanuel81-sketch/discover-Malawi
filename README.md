# Discover Malawi 🇲🇼

Discover the Warm Heart of Africa - Lake Malawi, Mulanje Mountain, Nyika Plateau, Liwonde National Park and more.

## Live Website
https://discover-malawi.onrender.com

## About
A tourism website for Malawi built with Python (Flask) to showcase Malawi's beautiful destinations, culture and wildlife to the world.

## Features
- Explore Destinations - Lake Malawi, Mulanje, Nyika, Liwonde, Zomba
- Travel Guide & Tips
- Admin Dashboard to add destinations
- Mobile-friendly design

## How to Run Locally
1. Download this project
2. Run python app.py
3. Open http://127.0.0.1:5000
